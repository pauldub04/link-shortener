# Сервис коротких ссылок

Консольное приложение для сокращения HTTP(S)-ссылок. Для каждой ссылки можно задать лимит переходов. Срок жизни берётся из настроек.

## Запуск

Команды выполняются из корня проекта с JDK 17.

```sh
./mvnw package
java -jar target/link-shortener.jar
```

В Windows для сборки используется `mvnw.cmd package`. Для открытия ссылок нужна графическая сессия с браузером по умолчанию. В Linux при недоступном `Desktop.browse()` используется `gio open`.

## Пример

```text
add https://example.com/articles/java 3
list
open short:000001
edit 000001 - 5
delete 000001
```

`short:000001` — пример первого кода в пустом хранилище. Для перехода можно ввести его целиком или выполнить `open 000001`. В `edit` дефис оставляет прежнее значение.

UUID появляется после первого `add` в новом профиле. Сохрани его для команды `use <uuid>` после перезапуска. Список, редактирование и удаление ссылок доступны владельцу. Для нового профиля введи `new`, затем `add`. Команда `help` показывает подсказку, `exit` завершает работу.

Последний разрешённый переход открывается, после чего ссылка блокируется. Просроченные ссылки тоже удаляются из активных. В обоих случаях владелец видит сообщение в консоли или получает его при следующем входе через `use`.

## Настройки

Параметры находятся в `application.properties`. Путь к другому файлу можно передать после имени JAR.

| Параметр | Значение | Что задаёт |
|---|---|---|
| `link.ttl.millis` | `86400000` | Срок жизни в миллисекундах, по умолчанию сутки |
| `link.limit.default` | `10` | Лимит по умолчанию для `add` |
| `link.limit.max` | `10000` | Максимальный лимит |
| `cleanup.interval.millis` | `1000` | Интервал фоновой очистки в миллисекундах |
| `storage.path` | `data/state.properties` | Файл со ссылками, профилями и уведомлениями, путь от каталога конфигурации |

## Код и тесты

- `shortener.core` выдаёт коды из счётчика в Base62 и следит за сроком действия, лимитами и правами владельца.
- `shortener.storage` читает настройки и сохраняет состояние между запусками.
- `shortener.cli` обрабатывает команды, запускает браузер и фоновую очистку.

`./mvnw test` запускает тесты. В GitHub Actions выполняется `./mvnw verify` со сборкой и Checkstyle.

Для ручной проверки создай ссылку с лимитом `1` и открой её два раза. Во второй раз консоль сообщит об исчерпанном лимите. Для проверки срока жизни можно поставить `link.ttl.millis=3000` и дождаться уведомления.
